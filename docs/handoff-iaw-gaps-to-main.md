# 交接清单：行业 AI 工作台（IAW）宿主面能力缺口 → main

> **来源**：2026-09-11 面板前端按《行业 AI 工作台 PRD v1.0》（IAW-DS 设计系统 + WorkBuddy 原型）
> 整体重构为五空间工作台时的**功能归属盘点**。定制轨（本分支）已交付界面与可落地的数据绑定；
> 下列能力属宿主平台域（模型网关 / 数据要素 / 事务流引擎 / 计量 / 审计 / IAM / Agent 域），
> 定制侧**不做前端假实现**——界面上诚实缺席并标注「已登记交接清单」，本文即登记处。
>
> **交接方向**：main 侧（宿主轨）实现后，定制侧仅需把面板对应视图的诚实占位换成真实数据绑定。
> 模板沿例：`docs/handoff-host-features-to-main.md`。

## 0. 已交付基线（定制侧，本次改版；2026-09-11 下午协作首位增补）

- 五空间信息架构（**协作首位** /图谱/执行/能力/数据；协作空间全屏时右侧协作栏自动收起）+ 底部事务流条 + 状态栏；
- 14 重点行业主题引擎（`data-industry` 令牌覆盖：主色/密度/动效，PRD §10）；
- 场景罗盘（环节链主线 + 价值标签过滤 + 业务活动泳道）+ 场景详情抽屉（概览/四要素/痛点/事务流/协作）；
- 图谱空间原型三视图落地：主线贯通（跨场景要素复用度）、场景对比（≤3 并排）、转型路线图（评级三阶段 + 快赢清单）；
- 度量驾驶舱（评级分布/价值标签/任务健康/渠道表/平台资产与漏斗——全部真实数据源）；
- 14 行业场景图谱包（`packages/platform-core/scenegraphs/`，333 场景——场景全量清单中四清单完整的 818 场景已尽收，其余 485 个原文缺要素/缺痛点，按「不造假数据」红线不入库）；
- Agent 流式应答卡（/agent-stream SSE-over-POST；@数字同事 → 增量渲染，落库广播不变）；
- 钉钉入向拉取（dws CLI：/api/panel/ddws/pull 幂等去重 + 60s 自动拉取；出向投递既有）；
- 既有服务行为全保留：登录三链、demoAuth、remote 代理、SSE+轮询降级、钉钉双源、草稿、XSS 白名单。
