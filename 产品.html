FEATURES

四大核心优势

六个 dist 预构建包随附基座，在全新安装的 dsh 上一条命令完成装机、启动与完整体验。

一键装机、开箱即用

dsh plugin add github:01men/RQ-DSH，npm / link / file 四通道任选；dist 预构建产物零 TS 装载、零生命周期脚本。

五空间、装完即有

协作 / 图谱 / 执行 / 能力 / 数据五空间信息架构 + 底部事务流条；连接宿主前，/gate01/panel/ 即见内置演示看板。

身份自带、登录无忧

钉钉设备流登录由面板代发起，未登录 / 未绑定自动弹激活指令；IAM / OIDC 身份基座随包，人与代理各自持票。

卸载干净、重装如新

dsh plugin remove 一键卸载干净、重装即恢复；build-id 指纹对账 + cordis 三链一致，杜绝"半新半旧"装机。

FAQ

常见问题

01门是协作前台，榕器 AIOS 是企业 AI 资源底座。单独安装即见内置演示看板；连接宿主后，全量数据经本机代理接入（浏览器零跨域），登录在宿主侧完成。宿主面需求在主仓库（01men/ybkk-AIOS）演进，定制分支经 merge 吸收上游。

这是本仓库的 fresh-install 铁律：每一次功能、面板更新，都必须在全新安装的 dsh 上通过 dsh plugin add 装机、启动、完整体验。selftest 内置"装机模拟"段，校验 build-id 指纹、cordis 三链一致与 files 覆盖闭包，缺一件即红。

打开 /gate01/panel/ 即见内置演示看板与预置行业图谱；未激活行业以只读演示预览呈现，可完整体验五空间信息架构、底部事务流条与 14 行业主题引擎。

面板代发起钉钉设备流授权：未登录或未绑定时自动弹出激活指令，扫码确认后身份回填。人类与 AI 代理各自持票入场，操作按真实身份留痕。

npm 通道（@ybkk/gate-01，已实发布 1.2.0）随版本升级，重装即恢复；dsh plugin remove 一键卸载干净、不留残留。scripts/release.mjs 一键发布链路含构建回归与发布验证，避免"半新半旧"装机。
