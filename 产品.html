给谁用

同一张底牌，三位决策者各取所需

企业 AI 落地卡在同一个地方：不是不够聪明，而是没人管得住。这页纸分别回答 CIO、CTO、CFO 最关心的那个问题。

CIO · 信息主管

看得见，管得住

"公司里到底有多少 AI 在跑？出了事谁负责？"

  • 六类 AI 资产一屏台账：MCP、Skill、Agent、应用、模型、存储，谁装的、连着什么、跑到哪一步，一目了然
  • 高危操作强制审批：上线 / 下线 / 下架 / 吊销全程留痕，高风险动作 fail-closed
  • 四类审计日志覆盖认证 / 授权 / 调用 / 变更，内审外审随时取证
CTO · 技术主管

装得上，养得起

"别给我又一个要养三年的架子。"

  • cordis 插件化架构：一条命令装机，卸载干净、重装如新，fresh-install 铁律写入自测
  • 契约冻结 v1 齐套：API / 权限 / 事件三面声明式清单，定制与升级互不惊扰
  • 端到端自测断言全绿（含安全攻击演练）；Node 原生运行，零构建黑盒
CFO · 财务主管

算得清，省得下

"AI 这钱花到哪去了？省得回来吗？"

  • 用量三维月报：部门 / Agent / Skill 的 tokens 消耗逐月穿透，账单不再是糊涂账
  • 成本穿透到内部采购口径，空转调用无处遁形——行业实测空转占 30–50%
  • 按团队 + 领域资产定价，为用到的部分付费；无隐藏结算语义

03 · 交付与定价

半天上线，按用到的部分付费

不接超过两周的定制——产品化的意思就是：今天签约，明天它就在你的钉钉里干活。

交付与定价口径

  • 按团队 + 领域资产定价：按开通团队规模与所选行业图谱包 / 场景包计价，不为用不到的部分付费
  • 制造业私有化交付项目制：现场数据不出厂，先跑通一个车间 / 一个部门，再谈扩展
  • 半天上线：全新环境一条命令装机，内置演示看板先体验、后激活
  • 用量透明：只呈现用量与内部成本穿透，不含任何隐藏结算语义
  • 开源可审计：两个仓库全部公开，安全与逻辑经得起逐行检查
  • 30 分钟演示：带上你们最关心的一个场景——成本也好、审批也好——现场看它怎么被管住

给技术团队的验证通道
